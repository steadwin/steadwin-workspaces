# STEADWIN Workspaces — Premium Next.js Website

Production-ready Next.js + TypeScript source for STEADWIN Workspaces.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Production build
```bash
npm run build
npm start
```

## Main pages
- `/` — premium homepage
- `/spaces` — workspace listings
- `/list-your-space` — partner onboarding
- `/contact` — contact page

## Git
The project is source-code ready for GitHub. Do not commit `.next` or `node_modules`.
